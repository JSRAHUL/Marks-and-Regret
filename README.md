# Marks & Regret — Student Grade Evaluation System

An interactive, modern web application designed for comprehensive student academic evaluation, grade analytics, and performance monitoring.

## 📌 Features

- **Intuitive Grade Calculation**: Input and evaluate coursework scores, tests, and assignments with real-time grade calculations.
- **Visual Analytics**: Interactive performance breakdown charts and regret/improvement margin calculations.
- **Modern UI/UX**: Responsive dark mode design built with Space Grotesk and JetBrains Mono typography.
- **Client-Side Processing**: Fast and fully accessible directly from any web browser without server dependencies.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or deploy with GitHub Pages:

1. Clone or download this repository.
2. Open `index.html` in Chrome, Firefox, Edge, or Safari.
