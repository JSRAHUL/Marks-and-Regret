Enter Marks
Type your name and your score out of 100. Decimals are fine — 87.5 works just as well as 87.
02
Analyze Performance
The system runs your score through the grading logic and calculates your grade point instantly.
03
Get Personalized Feedback
Receive a reality check written for your exact grade, plus the marks you need for the next one.
// about the project

About the Project

Marks & Regret is a Python based student grade evaluation system designed to calculate academic performance and provide personalized feedback. The project demonstrates conditional statements, functions, input validation, formatted output, and basic program structure in Python.
